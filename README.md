# Dinámica de una cuerda tensa bajo cargas móviles

Material interactivo del trabajo de titulación: **https://jorgejesus97.github.io/tesis-cuerda/**

| Página | Qué muestra |
|---|---|
| [Mapa de los tres casos](https://jorgejesus97.github.io/tesis-cuerda/mapa/) | Cómo se conectan los casos: el plano (α, μ), las ecuaciones de cada uno y sus límites |
| [Caso I: fuerza sin masa](https://jorgejesus97.github.io/tesis-cuerda/caso1/) | El frente de onda, las regiones que forman sus rebotes y la amplificación según la velocidad |
| [Caso II: cuerda sin masa](https://jorgejesus97.github.io/tesis-cuerda/caso2/) | El problema de Smith: cómo llega la partícula al apoyo final según λ |
| [Caso III: caso general](https://jorgejesus97.github.io/tesis-cuerda/caso3/) | El plano (α, μ) completo y la zona donde la partícula pierde el contacto |
| [Consola modal del Caso III](https://jorgejesus97.github.io/tesis-cuerda/consola-modal/) | El Caso III como suma de modos, comparado con los casos I y II |
| [Caso III por ondas](https://jorgejesus97.github.io/tesis-cuerda/app-ondas/) | App para el teléfono con la solución por ondas |
| [Caso III modal](https://jorgejesus97.github.io/tesis-cuerda/app-modal/) | App para el teléfono con la solución modal |
| [Ruleta del Caso III](https://jorgejesus97.github.io/tesis-cuerda/ruleta/) | Juego: ganas si la partícula llega al apoyo sin despegarse |

Parámetros: α = v/c, μ = m/(ρAL), λ = α²μ y n, el número de modos.

Cada página es un archivo HTML que corre en el navegador. No hay paso de compilación: GitHub Pages publica la rama `main` tal como está. Las consolas cargan MathJax y fuentes de Google; las apps y la portada no piden nada afuera.

La portada usa la fuente STIX Two Text, con licencia SIL Open Font License 1.1 (`recursos/fuentes/OFL.txt`).
